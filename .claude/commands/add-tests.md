Покрий тестами модуль: $ARGUMENTS

Роль: senior TypeScript-розробник; тести — це специфікація поведінки.

Контекст: раннер `vitest`, запуск `cd app && npm test`. Грошові суми в домені —
цілі числа в центах, ділення не має губити копійки.

Обмеження:
- НЕ змінюй продакшн-код. Падіння тесту — це знахідка, а не привід правити реалізацію.
- Не додавай залежностей і не міняй конфіг раннера.

Acceptance criteria:
- для кожної експортованої функції — типовий і крайовий вхід;
- явно покрито нуль, від'ємні значення, ділення із залишком, округлення;
- для функцій, що ділять суму, — перевірка інваріанта «сума частин = вхідна сума»;
- тести названі поведінкою, а не назвою функції.

Формат: спочатку файл тестів, потім список падінь
`тест → очікувано → фактично → ймовірна причина`.

Stop: після списку падінь зупинись, не виправляй реалізацію.
