# Слабкий промпт (baseline)

Стартова точка для Демо 1 і Task A. Вставте його у свіжий чат і подивіться, як
агент вгадує scope, стек і критерій «готово».

```
допоможи з тестами для app
```

## Чому він слабкий

- **Немає scope** — який файл? Агент читає все під `app/`.
- **Немає мети** — яка поведінка важлива? округлення? залишок центів? від'ємні суми?
- **Немає acceptance criteria** — агент сам вирішує, коли «готово».
- **Немає обмежень** — може правити продакшн-код, додавати залежності, міняти API.
- **Немає stop-правила** — працює далі, ніж корисно.

## Ваше завдання (Task A)

Перепишіть його у структурований промпт `prompts/add-tests.md` за
`prompts/_template.md`, наведіть на `app/src/quote.ts`, запустіть і переконайтеся,
що агент тримає scope, а `cd app && npm test` зелений.

> Підказка: у `quote.ts` є щонайменше одна реальна вада. Слабкий промпт її не
> знайде. Промпт з нормальними acceptance criteria — знайде.
